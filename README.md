# 🎨 Interactive Etch-a-Sketch

A dynamic, web-based digital sketchpad application inspired by the classic Etch-a-Sketch toy. Built using semantic HTML5, custom CSS3, and vanilla JavaScript, this project allows users to design 2D grid art natively in the browser by hovering or clicking with their mouse pointer.
